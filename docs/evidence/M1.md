- The crate was built with rustc 1.99.1, not 1.88; the 1.88 MSRV is declared in Cargo.toml and no 1.88 toolchain is installed here. `u64::is_multiple_of` is documented as stable since 1.87 (api-notes) but a 1.88 build was not run.

- `make demo` is wired to the M2/M3 `--demo` flags and is expected to fail until those flags exist; it was not run for the M1 gate.

## Limitations and known issues
- The M1 gate cannot pass until the SPEC §5.6 example and G9/review R3 agree on the second spawn cell (Q7).
- `make check` therefore exits 2 at `cli::tests::dump_has_the_exact_spec_shape`; the other 28 lib tests and all 4 non-conflicted CLI integration tests pass.
- The shell is headless, so this milestone proves only pure logic and storage, not any terminal output.

## Deviations and near-misses

- The program follows the normative RNG contract (§5.2/G9, cell 12) and therefore does not match the literal §5.6 dump example (cell 15). This is disclosed as Q7 instead of silently changing either side.
- The reviewer's three edits (`AGENTS.md`, `README.md`, `docs/reviews/M0.md`) were committed unchanged. `docs/reviews/M1.md` is left untracked and unchanged.
