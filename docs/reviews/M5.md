## Reviewer decisions (defaults for SPEC gaps; raise it if you disagree)
- **Geometry comes from the SPEC, not from the old renderer.** 9x5 cards, 39x23 board, 41x25 panel, exact rects above. Do not scale cards with the terminal.
- **Horizontal centring uses floor division** `(7 - len) / 2`, so 1- and 3-digit values are exactly centred and 2- and 4-digit values sit one cell left of mathematical centre. A terminal cell cannot be split; do not pad with a second space or a leading zero.
- **`BEST` keeps the existing styles.** The `BEST` segment uses `header_style()` when idle and `best_pulse_style()` while pulsing, so the M3 pulse test only changes where it looks for the token. `SCORE` uses `header_style()` too. Panel border uses the muted colour; the panel is rounded like the cards.
- **Keep the outer frame and its `2048` title.** This milestone adds a frame inside it; it does not remove the outer one.
- **Pacing helper is public and pure.** `next_frame_deadline` takes and returns `Instant`; tests use fixed instants, no sleeping. The live loop still forwards measured, clamped `dt` (250 ms cap) to `update`.
- **Self-test output** goes to stdout after restore, exactly one line, two decimals for seconds and a rounded integer for fps. Warnings stay on stderr; the two must not interleave.
- **`make e2e` capture path** becomes `docs/evidence/e2e/`. Old M4 captures are history and must not be rewritten.
- **Snapshot policy:** regenerate fixtures only for the changed layout; never add an auto-accept path. List every regenerated fixture and every retargeted test in the report.
- **No new dependencies and no new CLI flags.** If you believe one is needed, stop and report BLOCKED with the reason.
